# Paper 2 Replication Package

This package contains the final analysis dataset, replication code, verified
outputs for Paper 2, and an independent cross-repository audit against the
Paper 1 policy-measurement panel.

## Package structure

- `data/merged_autm.csv`: original final analysis dataset
- `data/verified_replication_dataset.csv`: clean 3,507-row analysis-ready dataset generated by the cross-repository audit
- `code/replication.py`: complete statistical analysis
- `code/run_all.py`: one-command Paper 2 replication runner
- `code/verify_cross_repo.py`: independent Paper 1-Paper 2 consistency check and clean-dataset builder
- `paper_outputs/logs/replication_output.txt`: complete verified Paper 2 results
- `paper_outputs/logs/cross_repo_verification.md`: human-readable cross-repository verification report
- `paper_outputs/logs/cross_repo_verification.json`: machine-readable verification results
- `requirements.txt`: Python dependencies

## Run the replication

Python 3.11 is recommended. From `P2_replication_package/`:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python code/run_all.py
```

The runner reads the final dataset, executes all analyses, and writes the
complete console output to
`paper_outputs/logs/replication_output.txt`.

The analysis can also be run directly:

```powershell
python code/replication.py
```

All paths are resolved relative to the package, so the scripts can be launched
from any working directory.

## Final dataset

`data/merged_autm.csv` is the original dataset required for Paper 2 replication.

- rows: `3,507`
- standardized institution names: `149`
- AUTM unit identifiers: `253`
- years: `1991-2023`
- rows with an NLP score: `2,564`
- verified SHA-256: `070f10179b34a0730d1f09ea3322d21e8f32e20d3036760df2adfef182aa2d4b`

The cross-repository audit pins Paper 1 at commit
`25a9472b34334825b6d6c6a334f5b88eb00695b5` and Paper 2 at base commit
`88cf4a1c02540b136adb8beaa35e212625ac755e`. All `2,564` Paper 2 rows with
an NLP score match Paper 1 on standardized institution and calendar year.
The following fields match exactly with zero discrepancies:

- `Mean_Tone_Score`
- `Median_Tone_Score`
- `Tone_Index`
- `Clarity_Index`
- `Legal_Load_Index`
- `n_sentences`
- `n_words`
- `Source_Year`
- `Is_Carried_Forward`

To rerun that audit and regenerate the clean analysis-ready dataset:

```powershell
python code/verify_cross_repo.py
```

This writes `data/verified_replication_dataset.csv` (3,507 rows, 46 columns)
and the cross-repository verification reports under `paper_outputs/logs/`.

## Analysis

The primary specification uses lagged `Mean_Tone_Score` as the Policy
Communication Index, institution and year fixed effects, institution-clustered
standard errors, and lagged institutional controls. Lags are matched by actual
calendar year, and the fixed effects are absorbed exactly for the unbalanced
estimation sample.

The independently re-estimated baseline coefficient for log new patent
applications is `0.615866` (`SE = 0.523368`, `p = 0.240590`, `N = 2,115`).
Rounded to manuscript precision, this is `0.616` (`SE = 0.523`, `p = 0.241`).
The serial-correlation-preserving 2,000-draw circular-shift placebo p-value is
`0.1929`.

The automated GitHub verification workflow also reruns the complete Paper 2
analysis and confirms that the regenerated `replication_output.txt` is
byte-for-byte identical to the committed verified output log.

The code also reproduces descriptive statistics, alternative outcomes, lag
checks through five years, heterogeneity estimates, multiple-testing
adjustments, leave-one-out estimates, and count-model robustness results.
